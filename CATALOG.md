# Outbound skills catalog

These 21 skills are grouped by the work they support. Sections 1–4 cover customer and offer definition, brand and design, content production, and campaign operations. Linked entries are available now. Other entries are planned. Each row identifies the output a team member or another skill can use.

| Section | Skill | Reusable output |
| --- | --- | --- |
| 1.1 | [Define the ICP](plugins/department-skills/skills/define-icp/SKILL.md) | Fit criteria, exclusions and evidence needed to decide |
| 1.2 | Define buying roles | Role brief with pains, authority and buying questions |
| 1.3 | Define the offer | Outcome, scope and next step the company can deliver |
| 1.4 | Build a proof library | Claims linked to evidence and permitted uses |
| 2.1 | Define the brand | Positioning and reasons to believe |
| 2.2 | Define brand voice | Annotated language examples and counterexamples |
| 2.3 | Define copywriting voice | Writing guide with worked edits |
| 2.4 | Define the visual system | Layout, typography, color and asset conventions |
| 2.5 | Retrieve brand assets | Correct file and usage guidance |
| 3.1 | Write brand copy | Reusable company and product descriptions |
| 3.2 | [Write conversion copy](plugins/department-skills/skills/write-conversion-copy/SKILL.md) | Page headline, supporting evidence and CTA |
| 3.3 | [Write outbound email](plugins/department-skills/skills/write-outbound-email/SKILL.md) | Buyer-specific email and follow-ups |
| 3.4 | Write LinkedIn outreach | Connection note and messages |
| 3.5 | Develop thought leadership | Attributed point of view and supporting argument |
| 3.6 | Write a LinkedIn post | Publishable post in the author's voice |
| 3.7 | Create a marketing one-sheet | Designed, sendable sales document |
| 4.1 | [Build a target-account list](plugins/department-skills/skills/build-target-accounts/SKILL.md) | Accounts with fit reasons and supporting evidence |
| 4.2 | Map and enrich buying contacts | Role-matched contacts with evidence |
| 4.3 | Build a campaign sequence | Ordered touches, timing, responsibilities and reply rules |
| 4.4 | Route replies and hand off opportunities | Disposition, owner and next action |
| 4.5 | Analyze outbound performance | Outcome by audience and message, plus a recommended change |
