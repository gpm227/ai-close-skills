# How to judge a department skill

Start with a decision a person needs to make or an artifact they need to use. For a sales pipeline review, a rep should be able to identify the deal, see what changed, and take the next action. For a brand system, a designer should be able to work from the approved handoff with the agreed type, colors, copy and usage limits.

## Acceptance standard

Use one point for each criterion. Score the output of a named version on a named case. Mark a check **unknown** when the evidence is missing. Record the input, output, source version, verdict and a short evidence pointer so another reviewer can reproduce the decision.

| Criterion | What to inspect |
| --- | --- |
| 1. Right job | A realistic request selects this skill. A nearby request for a different job routes elsewhere or gets an accurate scope explanation. |
| 2. Right inputs | The skill identifies which source, date, unit, audience or authority matters. It asks only for a missing decision that changes the result. |
| 3. Grounded decisions | A reviewer can trace every consequential claim or decision to a source, stated rule or labeled inference. |
| 4. Domain correctness | Recalculate a figure, reclassify a row, compare an edit with its rule, or inspect a design at the intended size. Check the decision the buyer will act on. |
| 5. Difficult input | A conflict, incomplete sample, blocked source or unknown permission produces a bounded result and the next action needed to resolve it. |
| 6. Usable handoff | A fresh person can use the result with only the intended deliverables. It includes the qualifying details, destination, owners or assets the task requires. |
| 7. Preserved constraints | Protected wording, permitted audience, excluded contacts, scope and other material restrictions survive the transformation. |
| 8. Worked practice case | A reader can start from supplied input and compare their output with an example and observable checks. An alternate case forces a different decision. |
| 9. Portable delivery | The individual ZIP includes its instructions, cases and required local resources. Referenced commands and paths work from the unpacked skill. Record native installation separately. |
| 10. Independent evidence | Someone outside the editing pass tries a new case, grades the actual artifact and records remaining gaps. For a revision, rerun the same input on the previous version when available. |

For visual jobs, reject a piece the owner considers interchangeable even when its tokens, copy and output files check out. Record the rejected version and the positive reference the owner selects. Rework the actual composition and show the next rendering. A 10/10 needs a pass on all ten. A hypothetical expected answer earns no credit for a successful live run. Record an owner's aesthetic or voice judgment separately from structural checks. Track whether a team actually used the result separately from both.

## Worked comparison

On the original brand pilot, the designer could see the intended composition and copy, but the handoff omitted the actual colors, type stacks and icon choices. The private guide held those decisions. To test an improvement, give a second designer only the intended design brief and assets. Ask for the three color roles, type and fallback, the wordmark treatment, and an icon assignment. Compare their answers with the supplied source material. Then inspect whether confidential notes appeared in anything intended for transfer.

Apply the same reasoning to a different job. For account qualification, introduce a duplicate location and an already excluded company with incomplete data. Inspect both the complete decision ledger and the eligible-only sales file. If the data is incomplete, the rep needs to know what evidence to find. For a month-to-date comparison, remove a date: a directional conclusion from the incomplete export fails the case.
