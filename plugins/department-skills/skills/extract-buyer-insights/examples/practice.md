# A theme is counted once per buyer account

Use these fictional transcript excerpts. Each line has a call, account and speaker. Treat the statements as internal research.

## Input

- C1/A/L03, rep: “Does approval take days?” L04, buyer: “Maybe. The file lands in my personal inbox.” L08, buyer: “If I'm off, no one sees it.”
- C2/A/L12, same account, another buyer: “Those files still go to one person's inbox.”
- C3/B/L04, rep: “Your approvals take days?” L05, buyer: “Sure, maybe.” L14, buyer: “We use a shared queue. Who can see the review history?”
- C4/C/L07, buyer: “Intake is shared. I need the warehouse lead to approve exceptions for another region.”

**Request.** Identify themes, count supporting accounts, call out counterexamples and suggest one expansion question.

## Decision key

Personal-inbox dependency has **1 of 3 accounts**, A. Cite C1/L04 or L08 and C2/L12; two calls and multiple speakers do not increase the account count. B and C describe shared intake. The assertion that approvals take days started with the rep; B's assent is weak and A expresses uncertainty. There is no independent measurement of wait time.

B asked who can see history (C3/L14); it is an access question, not proof of absent controls. C's cross-region approval need (C4/L07) supports a possible scope change. Ask who authorizes that regional workflow and what changes for the warehouse lead. No purchase decision follows. Retain source IDs with verbatim claims or label paraphrases, and keep company identifiers private in any external summary.

## Edge prompt

Remove the account mapping from C2. Do not count C2 as a new account. Show its unattributed evidence separately while preserving the count supported by identified accounts. If an excerpt is only a note without verbatim wording, report the note and its locator without quotation marks.
