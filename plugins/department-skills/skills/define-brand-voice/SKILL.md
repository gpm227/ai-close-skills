# Define brand voice

Plain AI writes a voice guide full of adjectives: "friendly but professional, confident but humble." Nobody can apply it, and every writer reads it differently.

## You'll need

- **Your current guide,** if one exists.
- **Before and after pairs.** Drafts and the edited versions that got approved. Ten pairs beats a hundred finished pieces.
- **Who reads it,** and where (website, email, proposals).

Set aside two or three pieces before you start. You'll test the guide on them.

## Steps

1. Compare each before and after line by line. Name what the edit fixed: a vaguer claim made specific, a weaker verb replaced, a missing next step added.
2. Separate voice (holds everywhere) from channel habits (only email, only social) and fact rules (never promise X).
3. Write each rule as: when, do this, except, source, and a one-line before and after.
4. A pattern seen once is provisional. Say so.
5. If examples conflict, keep the narrower rule and ask the owner.

## What you get back

A short guide: up to five rules, each with a before and after, plus the result of testing it on the pieces you set aside. Changes that need the owner's call are listed separately.

## The trap

The editor changed "We leverage cutting-edge AI" to "We check every report against your source data." The obvious rule is "avoid jargon." The useful rule is "Say what we do and to what. Replace any claim about technology with the action it performs."

## Check it

- Give a new writer one rule and one unseen draft. They make the same edit the editor would.
- No rule rests on a single example without being marked provisional.
