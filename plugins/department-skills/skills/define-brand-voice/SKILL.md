# Define brand voice

## Start with

Start with the existing approved guide when available. Bring paired drafts and revisions, audience and surface. Reserve an unseen sample before writing rules. If every sample comes from one channel, label which conclusions are channel-specific.

## Procedure

Compare exact passages and identify what the edit bought the reader: clearer ownership, narrower claim, better verb, useful detail or a truthful next step. Separate durable voice from channel conventions and factual rules. For each rule write the trigger, action, exception, source and a minimal before/after. Treat a preference inferred once as provisional. If examples conflict, preserve the narrower context and ask the lead only about decisions that would change output.

## Deliver

A short editorial standard with up to five high-value rules, annotated examples and a held-out review. Keep prior approved rules versioned. List changes requiring the lead’s decision separately.

## Check the result

Give a fresh reader one unseen passage. Have them identify the offer, responsible party and next action using the copy alone. A fluent rewrite that changes a fact fails. Never call inferred taste approved.
