# Compare vendor proposals

Use the quotes, expected volume, comparison period and any must-haves the buyer supplies. Accept pasted text or files. If a detail is missing, compare what can be established and identify the smallest question that would settle the decision.

Start with the decision the buyer can make today. Build a compact table with one column per offer. Cite the proposal section or supplied label for every material rate, commitment and exclusion. Separate buyer assumptions from vendor terms.

Compare equivalent quantities, currencies, time periods and service levels. Handle minimums, tiers, setup costs, overages, renewal terms and term commitments only when relevant. Show the arithmetic, rounding only the final totals. Separate cash due in the comparison period from any obligation beyond it. Unknown fees stay unknown. If a price or volume range could reverse the ranking, show the switch point or a bounded scenario where possible.

Check each must-have separately. Silence means unconfirmed. Label preferences separately and use only weights the buyer provided. Where requirements or scope differ, state what prevents a like-for-like choice. Close with the exact question to ask each vendor whose answer could change the decision.

Return the comparison and recommendation in the current workspace.
