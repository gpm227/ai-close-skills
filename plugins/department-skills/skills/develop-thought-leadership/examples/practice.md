# Practice · Make a narrow claim about approvals

## Run this request

“Draft a short opinion for studio leads on when to add a named reviewer. I want a useful decision at the end.” Fictional source packet cleared for anonymous discussion:

- N1, expert's retrospective, brief 14: two reviewers believed the other person had final approval. The file waited one workday.
- N2, brief 17: a named owner was available and the file still waited a day because the buyer had not supplied product dimensions.
- V1, expert's own phrasing: “I check what the file is waiting for before I change the meeting.”

## Worked argument

**Thesis.** Appoint a final reviewer when a ready file is waiting on an ownership decision. If a required input is missing, name who will supply it first.

**Counterargument.** Brief 17 already had an available reviewer. Its delay challenges the broader claim that appointing an owner prevents delay. The two records identify distinct blockers, not the relative frequency or impact of either.

| Point | Basis | Scope |
| --- | --- | --- |
| Two reviewers each expected the other to decide | N1, brief 14 | Observed once; one workday |
| A named reviewer could not supply missing dimensions | N2, brief 17 | Observed once; no universal timing inference |
| Check readiness before changing the approval process | Proposed action based on N1 and N2 | Test with a ready file and disputed authority |

**Draft**

I check what the file is waiting for before I change the meeting.

On one brief, two reviewers each thought the other had final approval. The file sat for a workday. A named decision-maker would have given the team someone to ask.

Another brief sat for a day with its reviewer available. The buyer still owed us product dimensions. Moving that review earlier would just have put an incomplete file in front of the same person.

Before assigning another approver, ask the person holding the file what they need next. If the file is ready and the decision belongs to nobody, name a reviewer. If a dimension is missing, give somebody the job of getting it.

**What would change this advice?** If the approver also owns the missing input in the studio's actual process, that assignment could address both blockers; verify who can provide the input before prescribing a handoff.
