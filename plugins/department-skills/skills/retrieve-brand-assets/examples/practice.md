# Choose a mark for a partner sign

## Request and inventory

Pick a logo for a fictional shop's public white-background booth sign, 600 mm wide. This is a manifest-only practice case. The file paths below are supplied by the asset owner; file bytes are unavailable.

| Source | Inventory | Approval |
| --- | --- | --- |
| M1 | marks/v3/rail-dark.svg, dark vector mark | Current owner manifest lists v3 for public print on white. Minimum application width 30 mm. |
| M2 | marks/v4/rail-dark.svg, dark vector mark | Internal proof for upcoming rebrand. Filename is newer than M1. |
| M3 | marks/v3/rail-white.png, white 180 × 60 raster | Current for dark web headers only. |
| M4 | images/partner-train.jpg | Photo licensed to a single internal training deck. |

## Worked result

**Select provisionally:** `marks/v3/rail-dark.svg` (M1), v3. The declared use, public-print rights, vector format, white background and 600 mm width match the request. Minimum reported width is 30 mm. The supplied manifest establishes a candidate; the file itself has not been opened. Ask for M1 or authorized access before production. Once opened, inspect the viewBox, aspect ratio, trims/clear space and a print-size crop. Confirm the printer's accepted vector format before delivery.

**Alternatives.** M2 is embargoed. M3 is white on white, too small, and cleared for another channel. M4 is outside its license. For a digital companion, standalone logo alt text can be “Rail Shop”; a decorative repeat beside the same name can have empty alt text. Printed signage has no HTML alt attribute.

## Boundary test

If the sign changes to a dark background, no listed file is both cleared for public dark-background print and verified at size. Return “no approved match,” request the dark-background print variant from the owner, and keep a labeled text-only placeholder in the internal layout. Never present the placeholder as the master or manufacture a recolor of M1 under its filename.
