# Review work against the brand standard

## Start with

Bring the standard and version, target surface, original draft, source claims, destination and optional corrections from previous runs. Keep review data private to the team unless cleared.

## Procedure

Read the draft as a first-time buyer. Quote the smallest failing span and identify rule, evidence, consequence and minimal repair. Mark factual and permission failures separately from voice preferences. Preserve passing language. Retest the finished copy, then run an unseen example on the same rule. If a repeat failure exposes a gap in the standard, prepare a separate proposed change with prior behavior, new behavior, regression and expected result. The lead approves a rule before release.

## Deliver

A verdict per criterion (pass, fail, unknown), revised draft and optional proposed change. Separate approval of wording from approval of a new standard. Record which tests actually ran.

## Check the result

If the copy is already approved and meets the standard, return it intact. One person’s stylistic preference should remain a note until the lead decides whether it is a shared rule.
