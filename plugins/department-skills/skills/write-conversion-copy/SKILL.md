# Write conversion copy

Use when a visitor has one commercial decision to make on a landing or product page. Identify the audience, entry source or ad promise, offer, eligibility, proof and permissions, approved voice examples and exact next screen. If the destination is unavailable, draft the supported page and ask one specific question about the unresolved CTA.

## Build the visitor's path

Start with the actual interaction. Write down what a visitor clicks, what immediately appears, what they provide, what they receive and when. Prefer a supplied route, screenshot or approved flow. Mark a destination described by the owner as reported until it can be inspected. Never generate a plausible live link to fill a gap.

Build the headline around the offer and its mechanism. Use a supporting line only when it adds a buyer, condition, mechanism or consequence. Resolve the objection most likely to prevent this specific next step. Include applicable pricing or eligibility conditions before the decision. Put proof adjacent to the claim it supports; leave out a proof block if none is cleared.

Deliver paste-ready copy by placement: desktop/mobile headline and CTA (reuse the same string when it fits), supporting copy, relevant proof and necessary friction or confirmation text. Keep claims, sources, qualifiers, CTA target and verification state in a separate editor note. Follow one full journey from arrival through confirmation. Verify that a short mobile button still promises the same action. State whether the path was exercised, documented by a supplied screen, or only described.

Treat expected conversion effects as hypotheses. A results claim needs a defined comparison, event, denominator and window.
