# Practice · Reach out after an event listing

## Run this request

“I'm not connected to Kim yet. Draft an invitation and follow-ups. I maintain an equipment handoff worksheet and would like to compare how teams design it.” Fictional source E1, program p. 2: “Kim Yen, session chair, depot equipment handoffs.” E2, the sender's cleared worksheet: an open repair row has both an equipment ID and a receiving owner. The sender did not attend and has never met Kim.

## Worked draft

| Stage | Paste-ready text | Basis |
| --- | --- | --- |
| New invitation | Kim, I maintain a depot handoff worksheet and saw you listed as chair of the session on equipment handoffs. I'd like to connect. | E1 and sender brief |
| After acceptance | Thanks for connecting, Kim. What part of a depot handoff is hardest to record clearly? | Asks about practice without asserting a problem |
| If no reply and the worksheet is still available | One field combination in my worksheet is the equipment ID next to the receiving owner for each open repair. I can send that row if it would help. | E2, a new concrete example with one offer |

The invitation contains 128 characters, including spaces and punctuation. It contains no offer to buy or book. No message implies the sender heard the session, read Kim's work or knows what Kim's organization uses. A response ends this planned sequence.

## Second request

“The invitation is already pending and Kim said by email that they prefer no further outreach.” Expected output: zero invitations and zero DMs. Record the cross-channel stop. A pending invitation is not permission to send the rest of the sequence.
