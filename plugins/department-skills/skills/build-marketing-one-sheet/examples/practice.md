# Practice · Make a one-sheet for a depot operator

## Run this request

“Create a Letter one-sheet for a depot operator deciding whether to try a shift handoff workshop. We need editable copy and a printable page.” This is a fictional exercise.

S1, approved rate card: $480 for one depot, one 60-minute remote workshop, one editable shift handoff sheet, one revision. The depot sends a sample handoff before the workshop. Software setup is excluded.

S2, approved demonstration sheet, row 3, permits an illustrative open repair row with equipment ID and receiving owner. The usable row reads “Cart 04 / Check left wheel / Evening supervisor.” The fictional depot's printed handoff ticket gives the open repair an amber edge, sets the equipment ID in block letters and gives the receiving owner a separate dark strip. Those three features may be reproduced for this offer. There is no measured time saving or cleared photography.

A1, owner-supplied action: email `workshops@example.org` to request dates. No self-booking or quote tool. The address is reserved for this example.

## The one-sheet for depot operators

[Open the editable Letter one-sheet](one-sheet.html). It includes scope, price, a labeled demonstration row, the buyer's input and one email action. The action and price are each visible without opening a second page. The email is printed as text so the paper copy still works.

**Evidence note.** S1 supports every quantity, the price and exclusion. The large open-repair ticket reproduces S2's three permitted fields, values and reading order. The amber open-repair edge, equipment identifier and receiving-owner strip are recognizable features from the supplied print piece. “Illustrative handoff row” stays on the sample. A1 supplies the address and next step.

**Inspect.** At half size, cover the headline and ask which piece of equipment needs work and who receives it. The ticket should answer both. At 100%, Letter, with browser headers/footers off, confirm the sample label, price, exclusion and email survive on one page. Inspect the on-screen email target. A working mail application or inbound delivery is outside the fixture. Try adapting the page to a bakery asking buyers to compare loaf sizes. A repair ticket with bakery nouns pasted in would fail: use a cleared loaf cross-section, package label or actual size comparison instead.

## Second request

“A buyer needs A4. Their approved flyer has no price, no logo rights and a contact form that only accepts callback requests.” Expected: use A4 print size, omit the uncleared logo, state the authorized pricing process only if supplied and label the request as a callback. Ask for the actual destination if missing. Verify page fit again because a Letter result does not settle the A4 layout.
