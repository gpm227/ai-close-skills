# Select a target market

## Inputs

Offer, capacity, buying roles, wins and losses with dates. Accept pasted material or files. Use the buyer’s definitions and label gaps that affect the result.

## Do the work

Separate hard eligibility from priority. Identify the economic buyer, user and approver from evidence; treat titles alone as leads. Compare segments using a buyer-owned measure of pain and an observable threshold. Show which exceptions need a lead’s decision.

## Return

Segment decision table, buyer roles and a measurable inclusion rule. Give the complete free result in the current workspace. Draft external actions for the user to review.

## Check before delivery

A growing customer segment also has high churn. Include retention in the comparison and flag the missing margin data before prioritizing it. Apply any additional acceptance conditions supplied by the team lead. Identify which checks passed and what remains unresolved.
