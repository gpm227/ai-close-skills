# Your house rules live here

Everything in `custom/` is yours. Pulls from upstream never touch it.

- `custom/<skill>.md` overrides one skill. Example: `custom/copywriting.md`.
- `custom/_house.md` applies to every skill that reads it.
- `custom/tools.md` lists the tools you actually use, so skills stop guessing.

See [../CUSTOMISING.md](../CUSTOMISING.md) for precedence, the review step, and a worked example.
