ASTER QUIRE   /   Library moves

Keep the shelf run readable.

Move an open-shelf collection with a record the collections manager can check at the other end.

The two endpoint checks

01   /   RECORD

Record both ends.

Before packing, write the first and last call number of each shelf run on the route sheet.

02   /   READ BACK

Read both ends back.

After shelving, compare those two call numbers with the route sheet. Flag a mismatch for the collections manager before the run reopens.

The check covers the endpoints. It does not certify the order of every book.

Bring a route sheet to your planning call.

Send an enquiry. A coordinator replies by email with a route-sheet sample and can discuss the move. The form does not issue an immediate download.
